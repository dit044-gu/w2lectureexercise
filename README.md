# Week 2 lecture exercise

Look at the file `DrawPolygons.java`.

Discuss the code in groups:
- This code works, but is not well designed or implemented. Which
  changes would make it better? Why?
- What do we mean by “better”?

Note, this is about thinking and discussing – not writing code!

# Bonus tasks if you want more challenge:

- What implementation changes are neeed to allow users to add new
  polygons by clicking?

- There is also a Python implementation in `DrawPolygons.java`. Are
  there any interesting differences between how Java and Python does
  classes and objects?
